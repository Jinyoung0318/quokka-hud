## 다시 뽑기

```
npm run shot
```

화면을 캡처하지 않고 **코드로 렌더합니다.** 실제 렌더 코드와 실제 CSS 로
한 프레임을 그리므로, 마우스 위치나 애니메이션 위상이 섞여 들어가지 않고
언제 뽑아도 같은 그림이 나옵니다. 마크업도 `index.html` 에서 가져오므로
화면이 바뀌면 그림도 따라옵니다.

만드는 쪽은 `scripts/shot/` 에 있습니다.
